About Me

Work / Projects

Retail Sales and Profit Prediction

This project uses machine learning techniques to analyze how pricing, discounts, and product categories affect retail sales and profit. The project includes data cleaning, visualization, predictive modeling, and model evaluation.

Skills used: Python, Pandas, Matplotlib, Scikit-Learn, Linear Regression, Random Forest

Key findings: Higher discounts were often connected to lower profit, and Random Forest performed better than Linear Regression for predicting sales.

Marathon Performance Prediction

This project analyzes NYC Marathon results to identify patterns that influence runner performance. Machine learning models were used to predict marathon performance and compare model results.

Skills used: Python, Pandas, Scikit-Learn, TensorFlow, Data Visualization

This project explores childcare cost data to understand pricing patterns across locations and childcare categories. The analysis focuses on data cleaning, summary statistics, and visual storytelling.
