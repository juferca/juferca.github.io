Movie Ratings Analysis

This project explores the relationship between movie critic ratings (Tomatometer) and audience ratings using Rotten Tomatoes movie data. Statistical analysis and visualization techniques were used to examine rating distributions, content ratings, movie runtimes, release years, and factors that influence critic and audience perceptions.

Skills used: Python, Pandas, NumPy, Statistical Analysis, Hypothesis Testing, Regression Modeling, Data Visualization, Exploratory Data Analysis (EDA), SciPy, StatsModels, Matplotlib, Seaborn

Key findings: Audience and critic ratings showed a moderate positive correlation (0.66), runtime had little influence on critic scores, and a multiple linear regression model explained approximately 46% of the variation in critic ratings using audience ratings, runtime, and content ratings.

Movie Audience Score Prediction

This project explores whether movie attributes and critic review data can be used to predict audience scores. The analysis uses Rotten Tomatoes movie and critic review data to compare critic ratings, audience ratings, rating differences, and movie characteristics.

Skills used: Python, Jupyter Notebook, Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn, Data Cleaning, Machine Learning

Key findings: Critic and audience ratings showed a positive relationship, but the connection was not perfect. Some movies had large differences between critic and audience scores, showing that audiences and critics do not always respond to movies the same way.
